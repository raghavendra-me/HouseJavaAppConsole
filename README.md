## 🎯 About <a name="about"></a>

Simple House Finder is a Java console application that allows users to search for houses to rent and landlords to list their properties. It provides a straightforward interface for managing house listings and rental inquiries.

## ✨ Features <a name="features"></a>

- 🏘️ View available house listings
- 🔍 Search for houses based on criteria (e.g., location, price range)
- 📝 Add new house listings (for landlords)
- 📞 Contact landlords for inquiries
- 👤 User authentication for tenants and landlords

## 🛠️ Prerequisites <a name="prerequisites"></a>

- Java Development Kit (JDK) 8 or higher
- Command-line interface (CLI)
